# 📒 株ノート

> なお、このアプリは学習用です。ニュースと株価の関係を整理して、自分で考えるための道具として作ります。売買を判断するものではありません。

興味のある銘柄について、**ニュースと株価チャートを並べて見て、メモを残す**ためのスマホ向けWebアプリです。
「このニュースのあと、株価はどう動いたか」「市場全体の動きと比べてどうか」を、勘ではなく記録から確認することを目的にしています。

試作版の銘柄：日本郵船（9101）／積水化学工業（4204）／ダイドーリミテッド（3205）

## できること

- 株価チャート（1か月〜全期間）と、ニュースがあった日・メモがある日の印
- 「市場と比較」：TOPIX連動ETF(1306)と開始日を100にそろえて重ねて表示
- チャートをタップすると、その日のニュースとメモを表示
- ニュースごとに、公開後の値動き（当日・3日・5日）と、市場に対する差を表示
- ニュースのタグ（決算／業界動向／為替・金利／規制・政策／株主還元／その他）。自動で仮判定し、あとから変更できる。タグ別の平均値動きも集計
- メモ：日付つきで保存。「メモ日の終値から現在まで」の変化を自動で表示（仮説の答え合わせ用）
- 「市場全体」タブ：TOPIX・日経平均のざっくりした動きと、市場ニュース
- メモの書き出し／読み込み（バックアップ用）

ニュースが15:30以降に出た場合や休日に出た場合は、次の営業日の値動きとして扱います。

## しくみ

- 画面は `index.html` / `app.js` / `style.css` だけ（ビルド不要）。
- `scripts/fetch_data.py` が株価（Yahoo!ファイナンス）とニュース（Googleニュース RSS）を取得し、`data/` に積み上げます。
- GitHub Actions（`.github/workflows/update.yml`）が平日の16:30（日本時間）に自動実行し、`data/` を更新します。
- メモとタグは、使っている端末のブラウザ内（localStorage）に保存されます。GitHubには送られません。

## 使い始める

1. このリポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にする。
2. **Actions → update-data → Run workflow** で、最初のデータを取得する。
3. 表示されたURLをiPhoneのSafariで開き、共有ボタンから「ホーム画面に追加」する。

## 銘柄を追加する

アプリの「＋銘柄を追加」に、証券コード・名前・業種を入れて「GitHubで申請」を押し、開いたIssueを作成（Create）します。
`add-stock` ワークフローが銘柄を `data/config.json` に追加し、株価とニュースを取得して、Issueに結果をコメントします（1〜2分）。
リポジトリの持ち主が作った、タイトルが「銘柄追加」で始まるIssueだけを受け付けます。

## 銘柄・検索語を直接変える

`data/config.json` を編集します。`queries` はニュース検索語です（`company`＝会社、`sector`＝業界）。
銘柄を足すときは `stocks` に1件追加します。`symbol` は日本株なら `証券コード.T` です。

## 注意

- 株価・ニュースは無料の非公式ソースから取得しており、遅延・欠落・仕様変更があり得ます。
- ニュースの履歴は、取得を始めた日から積み上がります（初回は約60日分）。
- ニュースと株価の動きの関係は、偶然や他の要因によることも多いです。件数が少ないうちの集計は目安として見てください。
