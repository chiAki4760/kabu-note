# 株ノート 開発メモ

最終更新：2026-10-29（夜）

## 目的

興味のある銘柄（すでに持っている銘柄の売り時、これから買いたい銘柄の買い時）について、
勘や感覚だけでなく、現実の世の中の動き（ニュース）と株価の関係から見られるように勉強するための道具。
売買を判断するものではない（アプリ内にも注意書きを表示している）。

## 決めたこと

| 項目 | 内容 |
| --- | --- |
| 対象 | 国内株のみ |
| 端末 | iPhone中心（ホーム画面に追加して使う） |
| ニュース | 銘柄・業種ごと＋市場全体はざっくり |

| 形 | 公開リポジトリ ＋ GitHub Pages ＋ GitHub Actions（サーバー不要・無料） |

| 試作の銘柄 | 日本郵船(9101)・積水化学工業(4204)・ダイドーリミテッド(3205)。2026-10-29 に川崎汽船(9107)を「＋銘柄を追加」から登録 |
| Claudeとの連携 | APIは使わない。アプリで「Claudeに聞く文章」を作ってコピーし、Claudeのアプリに貼り付ける方式（簿記アプリと同じ考え方）。GitHub Pages から直接Claudeを呼ぶにはAPI（有料）が必要になるため |
| 放送大学との関係 | 「身近な統計」「問題解決の数理」（2026年度2学期）の実践の場として使う。「📐 学習」タブに、各授業回に対応する機能を置く。結果が出始めたら note で公開を検討 |
| 予測の扱い | 売買判断ではなく、考え方の練習。予測を残して後で答え合わせし、その結果もClaudeに振り返ってもらう |

## 現在できること

- 株価チャート（1M/3M/6M/1Y/全部）、ニュースのあった日とメモのある日の印
- 「市場と比較」（TOPIX連動ETF 1306 と開始日=100で重ねる）
- チャートをタップ → その日のニュース・メモを表示
- ニュースごとの値動き（当日・3日・5日、市場比）。15:30以降と休日のニュースは次の営業日扱い
- ニュースのタグ（自動仮判定、手で変更可）とタグ別の平均値動き
- メモ（日付つき、メモ日の終値から現在までの変化を自動表示）、書き出し／読み込み
- 「市場全体」タブ（TOPIX・日経平均・市場ニュース）
- 「＋銘柄を追加」（Issue経由。add-stockワークフローが config.json を更新して取得）
- 平日16:30（日本時間）にActionsが自動でデータ更新
- 「🎯 予測と答え合わせ」：最新の終値から5または20営業日後に「上がる／横ばい／下がる」を予測し、理由を残す。期間がたつと当たり・外れと市場比を自動表示（横ばい＝±2%以内）
- 「🤖 Claudeと考える」：株価（選んでいる期間、最大約60行に間引き）・ニュース（日ごとにまとめ、1日3件まで表示）・タグ別平均・メモ・予測をまとめた文章をコピー。聞きたいことは「期間全体の解説と今後の見方」「チャートで選んだ日の解説」「自分の予測とメモの振り返り」から選ぶ。売買の推奨をしない・シナリオ形式・件数が少ないことを明記、などの条件を文章に含めている
- メモの書き出し／読み込みに予測（と AHP の比較）も含む
- チャートに25日移動平均、前日比に z スコア（直近1年の標準偏差で割った値）
- 「📐 学習」タブ（learn.js）
  - 分布：騰落率のヒストグラムと正規分布、基本統計量、|z|の日数と正規分布の比較、大きく動いた日（タップで銘柄画面へ）、箱ひげ図（統計 第3〜5・8回）
  - 相関・回帰：散布図、相関係数、回帰直線、寄与率、β、相関行列（統計 第13回／数理 第13回）
  - 検定：予測の当たりの二項検定（偶然の当たり率は予測日より前のデータから求める）、タグ別の市場比の95%信頼区間（統計 第7・10・11回）
  - 配分の最適化：100株単位の整数制約で全探索・欲張り法・連続緩和（射影つき最急降下法）、線形と平均分散の効用、リスクとリターンの散布図（数理 第1・2・9・12・14回）
  - AHP：評価基準3つ×銘柄3つの一対比較、幾何平均法、CI（数理 第6回）

## 既知の課題・メモ

- ニュースの履歴は取得開始日から積み上がる（初回は約60日分）。印の分布や「5日後の値動き」の集計は、使うほど意味が出る。
- Googleニュース検索は他社の記事が混ざる。対策として、タイトルに社名（config.json の `match`）がない「会社」記事は「業界」に回している。
- タグの自動判定は「その他」になりやすい。キーワードの追加余地あり。
- TOPIX連動ETF(1306)のデータに、2026-03-30・31だけ桁がずれた値（約380が37.6）が入っていた。fetch_data.py に、急に2.5倍以上動いて数日以内に元へ戻る値を取り除く処理（drop_spikes）を追加し、既存データからも削除。本当の急落（ストップ安など）は戻らないので残る。
- 直近1年では、日本郵船と市場（TOPIX）の相関は0.17と低い（積水化学は0.61、日本郵船と川崎汽船は0.84）。海運は市場全体より運賃や中東情勢など業界の要因で動いていたと考えられる。
- 日経平均は Yahoo の `^N225`、TOPIXは連動ETF `1306.T` で代用している。
- 野村證券の記事は、公式の公開フィード（RSS/API）が見当たらず、自動取得の対象にしていない。メモ欄にリンクを貼る使い方を想定。
- 株価・ニュースは無料の非公式ソース。遅延・欠落・仕様変更があり得る。
- 銘柄の削除機能はまだない（data/config.json を直接編集）。
- 業種は業界ニュースの検索語になる。「貨物」のような広い言葉だと航空貨物など遠い記事が入るので、同業の銘柄と同じ検索語（海運なら「海運 運賃 市況」）にそろえると比べやすい。
- 記事では略称が使われることがある（川崎汽船→「川汽」「Kライン」）。config.json の `match` に略称を入れておくと「会社」記事として拾える。会社名の検索で取れた記事は毎回判定し直すので、`match` を増やすと過去の記事にも反映される。
- 検索語を変えたり増やしたりしたときは、その検索語だけ60日分さかのぼって取得する（それ以外は直近14日分）。
- add-stock.yml のジョブ単位の env で `runner.temp` を使っていたため、ワークフローが不正と判定され push のたびに失敗メールが出ていた。各ステップの env に移して解決（2026-10-29）。

## 構成

- 画面：`index.html` / `app.js` / `style.css` / `manifest.webmanifest` / `icon-180.png`
- データ：`data/config.json`（銘柄・検索語）、`data/prices/*.json`、`data/news/*.json`
- 取得：`scripts/fetch_data.py`、銘柄追加：`scripts/add_stock.py`
- 自動実行：`.github/workflows/update.yml`（毎日の更新）、`add-stock.yml`（銘柄追加）
- メモ・予測・タグは、使っている端末のブラウザ（localStorage）にだけ保存される（キー：kabu.memos / kabu.preds / kabu.tags）
