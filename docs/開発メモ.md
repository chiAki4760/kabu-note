# 株ノート 開発メモ

最終更新：2026-10-28

## 目的

興味のある銘柄（すでに持っている銘柄の売り時、これから買いたい銘柄の買い時）について、
勘や感覚だけでなく、現実の世の中の動き（ニュース）と株価の関係から見られるように勉強するための道具。
売買を判断するものではない（アプリ内にも注意書きを表示している）。

## 決めたこと

| 項目 | 内容 |
| --- | --- |
| 対象 | 国内株のみ |
| 端末 | iPhone中心（ホーム画面に追加して使う） |
| ニュース | 銘柄・業種ごと＋市場全体はざっくり |
| 機能 | 見る＋メモを残す |
| 形 | 公開リポジトリ ＋ GitHub Pages ＋ GitHub Actions（サーバー不要・無料） |
| 公開にした理由 | 実際の保有銘柄を隠す必要はなく、興味のある銘柄の研究用のため |
| 別リポジトリにした理由 | 簿記アプリ（boki-app8-2）はnote公開や友人との共有があるため、触らない |
| 試作の銘柄 | 日本郵船(9101)・積水化学工業(4204)・ダイドーリミテッド(3205) |

## 現在できること

- 株価チャート（1M/3M/6M/1Y/全部）、ニュースのあった日とメモのある日の印
- 「市場と比較」（TOPIX連動ETF 1306 と開始日=100で重ねる）
- チャートをタップ → その日のニュース・メモを表示
- ニュースごとの値動き（当日・3日・5日、市場比）。15:30以降と休日のニュースは次の営業日扱い
- ニュースのタグ（自動仮判定、手で変更可）とタグ別の平均値動き
- メモ（日付つき、メモ日の終値から現在までの変化を自動表示）、書き出し／読み込み
- 「市場全体」タブ（TOPIX・日経平均・市場ニュース）
- 「＋銘柄を追加」（Issue経由。add-stockワークフローが config.json を更新して取得）
- 平日16:30（日本時間）にActionsが自動でデータ更新

## 既知の課題・メモ

- ニュースの履歴は取得開始日から積み上がる（初回は約60日分）。印の分布や「5日後の値動き」の集計は、使うほど意味が出る。
- Googleニュース検索は他社の記事が混ざる。対策として、タイトルに社名（config.json の `match`）がない「会社」記事は「業界」に回している。
- タグの自動判定は「その他」になりやすい。キーワードの追加余地あり。
- 日経平均は Yahoo の `^N225`、TOPIXは連動ETF `1306.T` で代用している。
- 野村證券の記事は、公式の公開フィード（RSS/API）が見当たらず、自動取得の対象にしていない。メモ欄にリンクを貼る使い方を想定。
- 株価・ニュースは無料の非公式ソース。遅延・欠落・仕様変更があり得る。
- 銘柄の削除機能はまだない（data/config.json を直接編集）。

## 次の候補

1. 適時開示（決算・増配などの会社発表）の取得（ニュースよりノイズが少ない）
2. ニュースの印が重なる日の見せ方の改善
3. タグ判定の改善（業界別キーワード）
4. 銘柄の削除機能
5. ニュース前後の値動きの集計を、期間・タグ・銘柄をまたいで見られるようにする

## 構成

- 画面：`index.html` / `app.js` / `style.css` / `manifest.webmanifest` / `icon-180.png`
- データ：`data/config.json`（銘柄・検索語）、`data/prices/*.json`、`data/news/*.json`
- 取得：`scripts/fetch_data.py`、銘柄追加：`scripts/add_stock.py`
- 自動実行：`.github/workflows/update.yml`（毎日の更新）、`add-stock.yml`（銘柄追加）
- メモとタグは、使っている端末のブラウザ（localStorage）にだけ保存される
